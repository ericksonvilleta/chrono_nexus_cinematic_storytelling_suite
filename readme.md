# CHRONO-NEXUS: ODYSSEY 🎬🌌

### Immersive Split-Screen Cinematic Storytelling & 3D Parallax Suite

**CHRONO-NEXUS: ODYSSEY** is an advanced, high-performance web application featuring a split-screen layout that pairs narrative storytelling with a reactive 3D parallax viewport and real-time Web Audio ambient soundscapes. Built entirely using vanilla web technologies, Tailwind CSS, and the HTML5 Canvas API with zero heavy external dependencies.

## ✨ Features & Architecture

### 1. 🖥️ Split-Screen Cinematic Layout
* **Left Narrative Panel:** Features interactive chapter acts (*Act I: The Singularity*, *Act II: Cyber Horizon*, *Act III: Deep Astral*), dynamic timestamps, narrative text, and clickable exploration vector nodes.
* **Right 3D Parallax Viewport:** Houses a floating holographic glassmorphism card that responds in real-time to mouse hover with 3D tilt perspective (`rotateX`, `rotateY`), accompanied by a multi-layered particle starfield canvas.

### 2. 🎵 Dynamic Web Audio Synthesizer
* **Ambient Soundscapes:** Generates procedural multi-oscillator chord progressions and sub-bass pulse tones that automatically re-tune according to the active story chapter.
* **Controls:** Includes an instant audio start overlay to bypass browser autoplay restrictions, plus a master mute toggle.

### 3. 🛸 Interactive Holographic UI & Telemetry
* Real-time metrics counters (Synchronicity percentage, Neural Load TB/s).
* Smooth animated neon orbital energy rings rendering on canvas behind the 3D card.
* Toast notification alerts for node interactions and chapter transitions.

## 🚀 Getting Started

No complex build steps, external media files, or package managers are required!

1. Clone or download this project.
2. Open the `index.html` file in any modern web browser (Chrome, Firefox, Safari, Edge).
3. Click **"LAUNCH CINEMATIC EXPERIENCE"** on the introductory overlay to unlock browser audio permissions and dive into the story.

## 🛠️ Technology Stack

* **HTML5 / CSS3** (Vanilla implementation)
* **Tailwind CSS** (via CDN for responsive layout and styling)
* **HTML5 Canvas API** (For parallax starfields and orbital vector rings)
* **Web Audio API** (For real-time procedural synthesizer chords)
* **FontAwesome & Google Fonts** (Outfit & JetBrains Mono)
